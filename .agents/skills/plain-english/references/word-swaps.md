# Word swaps

A longer list than the one in SKILL.md. Read this when you want a replacement
for a specific word, or when you are checking your own draft.

## Phrasal verbs

| Do not write | Write |
|---|---|
| back up the data | copy the data, save the data |
| break down the cost | split the cost, list the cost |
| bring up a service | start a service |
| build out the feature | build the feature |
| call out a problem | name a problem, report a problem |
| check out the branch | switch to the branch (git: `git checkout`) |
| clean up the code | simplify the code, remove dead code |
| come across an error | find an error |
| cut down the latency | reduce the latency |
| fall back to the cache | use the cache instead |
| fill out the form | complete the form |
| get rid of the column | remove the column |
| give up after 3 tries | stop after 3 tries |
| hold off on the deploy | wait before the deploy |
| lay out the schema | design the schema, show the schema |
| lock down the config | fix the config, restrict the config |
| pick up the message | read the message, receive the message |
| pull in a dependency | add a dependency |
| put together a plan | write a plan |
| ramp up the traffic | increase the traffic |
| roll out the change | release the change, deploy the change |
| shut down the server | stop the server |
| sort out the conflict | resolve the conflict |
| speed up the query | make the query faster |
| stand up a database | create a database |
| take down the service | stop the service |
| throw away the result | discard the result |
| wrap up the task | finish the task |
| zero in on the bug | find the bug |

Note: keep a phrasal verb when it is the literal name of a command or API.
`git checkout`, `docker compose down`, and `SIGTERM shutdown` are names, not
prose. Do not rename them.

## Rare words

| Do not write | Write |
|---|---|
| leverage | use |
| utilize | use |
| facilitate | help, allow |
| endeavor | try |
| ascertain | find out, check |
| commence | start |
| terminate | stop, end |
| subsequent | next, later |
| prior to | before |
| regarding | about |
| numerous | many |
| sufficient | enough |
| demonstrate | show |
| implement (in prose) | build, add, write |
| furnish | give, provide |
| requisite | required |
| myriad | many |
| paramount | most important |
| albeit | although |
| hence | so |
| thereby | so, which means |
| notwithstanding | even so, despite that |

Note: `implement` is fine as an engineering term ("implement the interface").
Avoid it only as a fancy synonym for "write".

## Literary phrases

These add no meaning. Delete them or replace them with the plain version.

| Do not write | Write |
|---|---|
| the sharper line is | the real difference is |
| that lands close to | that is close to |
| worth naming | note that, or just say it |
| it bears mentioning | (delete, just say it) |
| surfaced a problem | found a problem |
| a real win | it helps because... |
| the honest answer is | (delete, just answer) |
| at the end of the day | (delete) |
| needless to say | (delete) |
| it goes without saying | (delete) |
| in order to | to |
| due to the fact that | because |
| for the purpose of | to |
| in the event that | if |
| a number of | some, many, or the exact number |

## Marketing adjectives

Delete these, or replace them with the measurement that proves the claim.

seamless, robust, powerful, cutting-edge, effortless, blazing-fast, elegant,
best-in-class, world-class, next-generation, lightning-fast, rock-solid

Write "the query takes 12ms", not "the query is blazing-fast".
